# YuvaIntern — Data Science with Python Apprenticeship

Projects and assignments completed during the Virtual Data Science with Python Apprentice Internship at YuvaIntern.

**Intern:** Rinsha Sherin

## 📂 Weekly Projects

| Week | Project | Description |
|---|---|---|
| Week 2 | Advanced Data Visualization & Storytelling | Built 6 narrative visualizations from a global retail transactions dataset (sales trend, category profitability, discount vs. margin, regional heatmap, customer segment mix, sub-category profit) to communicate business insights to a non-technical audience. |
| Week 3 | Statistical Analysis & Hypothesis Testing | Tested whether product category and discount rate are statistically associated with profit margin, using one-way ANOVA, Bonferroni-corrected Welch's t-tests, a chi-square test of independence, and linear regression, with Levene's test used to check the equal-variance assumption and confidence intervals reported throughout. |
| Week 4 | Machine Learning Model Development & Evaluation | Built and compared Logistic Regression and Decision Tree classifiers to predict loss-making transactions at order time, evaluated with a confusion matrix, ROC and precision-recall curves, and cross-validation, with a dedicated discussion of overfitting. |
| Week 5 | Comprehensive Project Report & Strategic Recommendations | Synthesized Weeks 2–4 into a single end-to-end report with an executive summary, integrated findings, and 5 prioritized strategic recommendations for stakeholders. |

*(This repository documents the full internship; all weeks above are complete.)*
